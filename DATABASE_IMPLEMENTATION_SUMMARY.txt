## 🔧 Common Usage Patterns

### Daily Development
```bash
# Morning check
make db-health

# Create migration
./scripts/db-migrations.sh create add_feature_x

# Apply changes
make db-migrate

# Verify
make db-status
```

### Performance Investigation
```bash
# Collect metrics
make db-optimize

# Check slow queries
DB_LOG_LEVEL=info docker compose up backend

# Analyze specific query
docker compose exec postgres psql -U thanawy -d thanawy << EOF
EXPLAIN ANALYZE SELECT * FROM table WHERE condition;
EOF
```

### Production Deployment
```bash
# Backup before deploy
make db-backup

# Run migrations
make db-migrate

# Verify
make db-status

# Monitor
make db-health
```

### Troubleshooting
```bash
# Full diagnostics
make db-health

# Check logs
docker compose logs postgres | tail -100

# Open shell
make db-shell
```
